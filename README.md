# Medical Insurance Cost Predictor

An AI-based project that predicts a person's estimated yearly and monthly
medical insurance cost using Machine Learning (Random Forest Regression).

## How it works
The model is trained on historical insurance data (age, sex, BMI, number of
children, smoking status, and region) to learn the relationship between
these factors and actual insurance charges. A user can then enter their own
details through a simple console program to get an instant cost estimate.

## Files
- `insurance_predictor.py` — main Python script
- `insurance dataset.xlsx` — dataset used to train the model

## Built with
Python, pandas, scikit-learn, matplotlib
